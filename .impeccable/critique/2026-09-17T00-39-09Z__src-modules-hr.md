## Design Specificity Verdict

LLM assessment: the content is authored for a Nepali restaurant; the structure is not. Specific: "Dashain allowance (चाडपर्व खर्च)", "Bereavement (Kiriya)", Gazette holiday seeding with a coverage report, BS worked examples in footnotes, a Crest Staff Today screen that separates unpublished from off. Generic: ~all 20 routes share one shell — hand-rolled KPI cards, chip row, wide table, 11px footnote, 12px toolbar status message. The central object, the payroll month (not started → draft → stale → finalized → deposited), has no visual home; HR uses no PeriodScope.

Deterministic scan: 3 findings, all design-system-color, all leaveConstants.js:19,21,22 (sick/maternity/paternity seed hexes). False positives — the file's own comment declares a categorical palette rendered only via typeTint/typeText; B measured every leave chip >=4.51:1 Light / >=8.2:1 Night — but not a DESIGN.md-named exemption, so they recur until an ignore-value entry is added. ## Overall Impression

The money path's integrity is the best in the product. What fails is everything around the figures: correct numbers painted as verdicts, the commit button shrunk to 12px, a month with no status anywhere, and a staff front door that speaks Postgres. Biggest opportunity: give the payroll month one home — attendance → approvals → run → finalize → deposit, visible and linked.
