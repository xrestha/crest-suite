## Implementation Integrity Verdict — PASS on specificity, held at 2 by one class

The implementation expresses a coherent, product-specific system. The detector returns zero failures across 318 source files; every colour on 95 live routes re-tones between presets from `--theme-*` tokens (the Light pass renders correctly everywhere — its failures are pattern misuses, not missing tokens); the product's own vocabularies are genuinely adopted where they were written (`HR_REQUEST_STATUS` on all five HR queues and the phone app, `posSignals.js` on 10 POS screens, `lcBand`/`fcBand` on the dashboards and roster, `fetchAllRows` on 78 files with `.order('id')` tiebreakers, `page-header` on 85/85 pages, `table-wrap` on 98/100). Copy, BS calendar, NPR formatting and IRD artefacts make it unmistakably this product.

What holds the score at 2 is a single shape repeated ~230 times: `const { data } = await …` with no `error` (109 sites) and bare `await scopedUpdate/Insert/Delete(…)` (122 sites). CLAUDE.md names this class three ways ("a try/catch around a supabase call catches nothing", "a guard that drops its read error passes vacuously", "a failed poll that writes its empty result blanks live state") and each of the four groups found it inside a money or safety path — see the P1 list. The S654 sweep fixed `PosOrders.jsx` and stopped; the S613 sweep fixed report *renders* and stopped at write and guard paths, exactly as the 2026-08-26 critique predicted.

## Patterns & systemic issues

1. **Dropped `error` is the product's one systemic defect.** ~230 sites; verified inside 13 P1 money/safety paths. The three sweeps that addressed it (S613 report renders, S654 PosOrders, S656 Purchases cache) each stopped at a file or a render boundary. The next sweep must be partitioned by *path type* — guard reads, batch-save loaders, polls, second-of-two writes — not by file.
2. **Pattern adoption is uneven in the same direction every time**: `ConfirmModal` (4 HR files, ~40 native confirms elsewhere), `ActionError`/`errorText.js` (0 HR files, 2 POS files), `useLatestRequest` (24 files; 20 select-driven pages without), `.btn-sm` (S680 made it real; ~40 row buttons still hand-size to 11px). Each was built, adopted on the page that prompted it, and never swept. Grep uptake before assuming a pattern landed.
3. **Base token as text on Light** recurs wherever a colour is passed as a prop or constant rather than a class — `KCard color=`, `GOLD`, `TREND_COLORS`, `EMPLOYEE_STATUS_COLORS`, hand-rolled tabs. The `.badge-*`/`STATUS_TINT.textColor` two-key rule is the fix and is already documented.
4. **Hand-rolled copies of shell classes** — 13 HR `inp` objects, 4+3 hand-rolled dialogs, a third tab family in Settings — each escapes the disabled/invalid/focus/coarse treatments the class carries.
